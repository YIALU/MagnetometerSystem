# 协议校验与通道单位

## ZDZ_C08 内置预设的 CRC 状态

“磁梯度数采卡-pt”及“仅磁场6通道”预设的帧布局已有样本，但固件 CRC 的确切变体、初值、计算范围和输出字节序仍未确认。两预设现在要求有效校验配置；默认连接会明确提示“CRC 参数待确认”，不会把 CRC 当作填充而保存可能损坏的载荷。

拿到固件方确认的参数后，在连接页面的段编辑器中：

1. 删除名为“CRC参数待确认”的两字节占位段。
2. 添加“校验”段，用上移按钮放到帧尾前；选 CRC16，并设置 2 字节。
3. 根据确认的协议选择 CRC 变体、起始段（从 0 开始）和校验值字节序。校验范围止于校验段之前。
4. 用已知有效帧和故意修改载荷的坏帧验证后，保存为自定义协议并连接。

若设备变体或校验范围尚不受编辑器支持，应先扩展解析能力；不要任意选择一个算法绕过提示。`RequireChecksum` 是通用协议属性，不按设备名称判断。旧版本已经保存的自定义 JSON 没有该属性，仍保留原行为；使用旧配置前必须检查并补充校验要求与参数，不能把加载成功理解为数据完整性验证成功。

单元测试对样本的字段布局使用明确标注的测试 CRC 重写校验字节；它们不证明原样本 CRC 或真实固件参数正确。需要固件确认后另做实体设备验收。

## 单位与显示

每个数据段和旧字段映射都可保存 `Unit`；单位按通道索引传入实时曲线。单图将不同单位放到独立 Y 轴，多图在各通道轴上标注单位；拖动通道次序不改变物理数据对应关系。

“主 Y 轴自适应”和手动范围控制每个图的左侧主轴。单图中其他单位轴始终按自身数据自适应；例如 nT 主轴的手动数值范围不会套用到 °C 温度轴。

ZDZ_C08 的六个磁分量及三项差值为 nT，GPS 为 °，加速度为 m/s²，陀螺为 °/s，深度为 m。额外三路磁力仪单位未确认，标为“设备单位”而不猜测为 nT；使用前应按固件输出更新它们。

## 设备存储下载边界

ZDZ 的“读取存储数据”（`90 9F`）会返回与实时测量相同布局的历史帧。独立下载接收流程尚未实现，因此该内置命令标记为 `RequiresIsolatedTransfer`，普通发送入口会拒绝写出并提示暂不可用；目录查询、时间选择和停止读取继续可用。本机 SQLite 会话的 CSV 导出不受影响。普通自定义命令和自由 HEX 不具备下载隔离能力，不能据此宣称支持设备内部历史数据导入。
