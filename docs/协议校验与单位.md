# 协议校验与通道单位

## 校验开关与 ZDZ_C08 的 CRC

二进制协议的校验段有“启用校验”开关。帧里预留了校验字段、但固件尚未计算时关闭它：这几个字节照常占位，解析时不比对；算法、起始段、CRC 变体和字节序都保留，固件启用后勾选即可。解析记录中通过的帧会注明“校验未启用”。没有该字段的旧协议 JSON 按启用处理，保持原来的校验行为。

“磁梯度数采卡-pt”及“仅磁场6通道”预设的帧里有 CRC 字段，但固件没有启用计算：文档样本的 `BD 67` 与设备实测记录的 `C6 48` 对不上任何 CRC 参数组合。两预设的校验段按文档预置为 CRC-16/MODBUS、自“信息ID”段起、低字节在前，默认不启用，选上即可连接。CCT-5 的 CRC-16/IBM 校验保持启用。

校验未启用时，错位、丢字节和半帧仍由固定帧长、帧头、信息 ID、长度值和帧尾拒绝，但载荷内个别位出错无法发现，会按解析出的值保存。这是固件未启用 CRC 的限制，界面和解析记录会如实标明。

固件启用 CRC 后，在连接页面的段编辑器中：

1. 在校验段勾选“启用校验”。
2. 按固件协议核对 CRC 变体、起始段（从 0 开始）和校验值字节序。校验范围止于校验段之前。
3. 用已知有效帧和故意修改载荷的坏帧验证后，保存为自定义协议并连接。

v0.5.3 及以前保存的副本把 CRC 字节存为名为“CRC参数待确认（请配置校验段）”的占位段，并要求校验；加载时自动换成同样的未启用校验段。`RequireChecksum` 仍是通用协议属性，不按设备名称判断：协议要求校验却没有校验段时照旧拒绝连接。

单元测试保留原始样本字节验证字段布局；“启用校验”路径和损坏帧测试使用明确标注的合成 CRC。它们不证明真实固件的 CRC 参数。固件启用 CRC 后需另做实体设备验收。

## 可变长度段

`LengthField` 表示长度段结束后，到校验段（无校验时到帧尾）之前的数据区字节数，包含保留区。已映射字段与固定值锚点必须完整存在；尾部未映射的字节可以增减。校验和帧尾位置随实际长度移动，无长度段的固定帧仍按配置长度解析。

## 单位与显示

每个数据段和旧字段映射都可保存 `Unit`；单位按通道索引传入实时曲线。单图将不同单位放到独立 Y 轴，多图在各通道轴上标注单位；拖动通道次序不改变物理数据对应关系。

“主 Y 轴自适应”和手动范围控制每个图的左侧主轴。单图中其他单位轴始终按自身数据自适应；例如 nT 主轴的手动数值范围不会套用到 °C 温度轴。

ZDZ_C08 的六个磁分量及三项差值为 nT，GPS 为 °，加速度为 m/s²，陀螺为 °/s，深度为 m。额外三路磁力仪单位未确认，标为“设备单位”而不猜测为 nT；使用前应按固件输出更新它们。

## 设备存储下载边界

ZDZ 的“读取存储数据”（`90 9F`）会返回与实时测量相同布局的历史帧。独立下载接收流程尚未实现，因此该内置命令标记为 `RequiresIsolatedTransfer`，普通发送入口会拒绝写出并提示暂不可用；目录查询、时间选择和停止读取继续可用。本机 SQLite 会话的 CSV 导出不受影响。普通自定义命令和自由 HEX 不具备下载隔离能力，不能据此宣称支持设备内部历史数据导入。

## 标称采样率与回放时间轴

会话的 SampleRate 记录连接时填写的标称值，不表示设备已确认的实际输出频率。发送采样率命令不会隐式修改此元数据，也不能仅凭本地写出推断设备已经执行。设备在会话中改变频率时，读数仍按原始时间戳保存；回放依据记录时间戳间隔和选择的倍速调度，不按标称值重建时间轴，不强制拆分会话。没有设备时间戳的协议使用解析时刻，串口或网络缓冲造成的时间精度限制仍然存在。
